# Киноафиша

Учебный проект по дисциплине «Web-технологии»: сайт кинотеатра с афишей,
карточкой фильма и формой добавления нового фильма.

## Возможности

- **Афиша** — сетка карточек фильмов, отсортированная по ближайшему сеансу.
- **Карточка фильма** — постер, описание и расписание сеансов с залами и ценами.
- **Добавление фильма** — форма с проверкой полей и динамическим списком сеансов.
- **Редактирование и удаление** — та же форма для изменения фильма и его предстоящих сеансов; удаление с подтверждением.
- **О проекте** — описание, возможности и стек (`/about`).

## Стек

| Часть | Технологии |
| --- | --- |
| Бэкенд | Java 17, Spring Boot 3.5.4, Spring Data JPA, Maven |
| База данных | PostgreSQL 16 |
| Фронтенд | React 19, TypeScript, Vite, LESS, React Router, axios |
| Запуск | Docker Compose |

## Структура

```
cinema-frontend/src
├── api/         запросы к бэкенду и обработка ошибок
├── components/  переиспользуемые компоненты (форма, поля, карточка)
├── pages/       страницы приложения
├── helpers/     форматирование дат, цен, длительности
└── types/       типы DTO
```

## Запуск

### Через Docker

```bash
docker compose up --build
```

Открыть **http://localhost:8081**.

### Для разработки

```bash
# база данных
docker compose up -d db

# бэкенд — http://localhost:8085
cd cinema-backend && ./mvnw spring-boot:run

# фронтенд — http://localhost:7120, /api проксируется на бэкенд
cd cinema-frontend && npm ci && npm run dev
```
